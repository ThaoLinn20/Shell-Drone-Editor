## Features
- Added GPU accelerated smoke simulation option for ultra-smooth performance with dense firework smoke.
- Added Smoke Trail to the active effects timeline with customizable timing and duration.
- Added multi-selection stretch and spacing distribution tools on the timeline for fast sequence re-timing.
- Added Recent Scripts tab in Show Library to quickly reopen and manage recently saved shows.
- Added Terminal Flare Color Picker with custom color swatches and per-particle random colors in Property Inspector.
- Added Known Issues and Workarounds dialog accessible from the timeline toolbar with instant guidance for common system questions.

## Bug Fixes
- Corrected Smoke Trail effect timing so smoke particles emit continuously along the flight path from launch.
- Fixed onboarding guide navigation flow to seamlessly align with the updated dual-tab show library modal.

## Updates
- Stabilized launch trajectory height calculations across all procedural firework patterns.
