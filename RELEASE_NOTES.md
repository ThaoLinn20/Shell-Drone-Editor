## Features
- Added a unified Guide Hub modal featuring category tags and accent-insensitive instant search to help you quickly find relevant walkthroughs.
- Added an interactive first-launch Overview guide that highlights the Guide Hub button and helps new users pick their preferred tutorial right away.
- Added hands-on spotlight walkthroughs for creating, saving, and exporting a script from scratch, exporting and reusing block clusters, and getting started with sample shows.
- Added a Show Script Library browser that lets you link a local scripts folder, automatically checks companion audio availability, warns if downloaded archives still need extraction, and imports shows in one click.
- Added support for right-clicking empty timeline space to jump the insertion cursor directly to that spot and open quick actions for pasting, adding a sequence, or inserting saved Drone and Shell clusters.

## Updates
- Updated all new tutorials, toolbar controls, context menus, and library screens with complete translations in English, Vietnamese, Chinese, and Japanese.
- Improved resource cleanup and audio track handling when switching between scripts or opening new shows from the library.
