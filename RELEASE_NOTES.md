## Features
- Added a quick language selector right next to the Guide button on the Timeline toolbar with a reload warning before switching between English, Vietnamese, Chinese, and Japanese.
- Added an isolated sequence preview bar inside the Property Inspector so you can test selected firework or drone blocks without moving your main timeline position.
- Added step-by-step interactive Property Inspector guides with Back and Next Guide navigation for configuring shells, launch positions, effects, and custom sequences.
- Added an interactive Timeline Editing and Mouse Controls guide covering dragging, resizing, multi-selection, and panning.
- Added an 11-step interactive Audio Import and Beat Mapping guide for importing music, detecting beats, tapping live beats, and cleaning up beat markers.
- Expanded the Export and Reuse Blocks guide with starter steps introducing sequence blocks and how to add them to the timeline.

## Updates
- Reorganized interactive guide modules for cleaner maintenance and smoother guide transitions without screen flashes or premature step jumps while typing numbers.
